# BeatWatch
A TensorFlow CNN model classifies ECG images as normal or abnormal. It is evaluated using a test dataset for accuracy and integrated into a Flask web application where users upload ECG images, the model processes them, and returns the prediction result.
Note: The trained CNN model file is large and cannot be uploaded to GitHub.
